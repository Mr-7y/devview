Ai-View

          
极简代码浏览器 · 可编辑 · 双主题 · 顶部 git 工作流

          
打开本地目录，树形浏览、语法高亮、变更标记与单文件 diff 都在一个窗口里完成。默认行高 1.9，代码区左右留白 26px，长时间阅读不压眼。

          
安装

          
# Windows
Ai-View-1.0.0-x64.msi

# macOS (Universal)
Ai-View-1.0.0-universal.dmg

# Linux
chmod +x Ai-View-1.0.0-x86_64.AppImage

          
三个安装包都自带运行时，不需要额外安装 Node、Python 或 WebView2。
