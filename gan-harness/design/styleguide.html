Ai-View / Design Specification · 2026

把代码放回
阅读的位置。

Ai-View 是一款可编辑、可换肤、以 git 工作流为顶栏的桌面代码浏览器。它不试图成为 IDE，而是先把“读代码”这件事做舒服：更大的行距、更暖的中性色、更少但更明确的界面噪音。

01 / PROPOSITION

编辑器为输入优化，
Ai-View 先为阅读优化。

主流代码浏览器被两种范式统治：VS Code 的蓝色工作台与 JetBrains 的高密度灰。它们都为效率服务，代价是视觉压迫。Ai-View 把“阅读”当作第一场景，重新分配留白、行距与颜色预算。

01 — AIR

呼吸

代码行高默认 1.90，左右留白 26px。面板之间只用 1px 发丝线分隔，不用重描边和阴影堆叠。长文件连读 30 分钟不压眼。

02 — ORDER

秩序

git 工作流常驻顶栏：分支、远程、ahead / behind、提交信息与推送按钮在同一条视线内。提交不是藏在侧边栏里的动作。

03 — WARMTH

温度

墨、纸、黄铜。用暖中性色替代冷灰蓝，强调色只用于状态：修改是黄铜，新增是玉色，删除是砖红。

02 / COLOR

两套主题，
两种完整的纸。

亮色不是暗色的反相。夜航用墨黑与黄铜，日纸用暖白纸底与深棕强调；阴影、发丝线与代码 token 都单独调过。

03 / TYPE

界面克制，
代码舒展。

界面字体走系统无衬线，避免下载；代码字体可在 JetBrains Mono、Cascadia Code、Consolas 与 SF Mono 之间切换。字号 12–20px、行高 1.4–2.3 连续可调。

界面字阶。标题用衬线只出现在品牌与规格页，产品内部保持无衬线，避免与代码抢注意力。

04 / COMPONENTS

少而明确。

控件高度集中在 24–33px，圆角 6–8px，状态只靠颜色与 1px 描边区分。所有动效 120–220ms，只服务于状态变化。

05 / PACKAGING

双击即用，

06 / RHYTHM

8px 的秩序，
220ms 的克制。

所有间距落在 8px 栅格上。动效只用于状态变化：悬停 120ms、面板切换 180ms、主题过渡 220ms，统一 ease-out。
